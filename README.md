# Дизайн и смета квартиры, Казань

Двушка 56,12 м², тёплый минимализм. Старт — предчистовая. Без гарнитура и мягкой мебели в цифрах ремонта.

## Что загрузить на GitHub

| Файл | Зачем |
|---|---|
| `SMETA.md` | полная смета, две колонки (референс / оптимум), линолеум |
| `smeta.csv` | та же смета для Excel |
| `visuals/` | 3D-визуализации |

## Итог сметы (Казань)

- Вариант А: **~2,88 млн ₽** (референс, пол — линолеум)
- Вариант Б: **~1,73–1,90 млн ₽** (умные замены)
- Пол: линолеум везде, кроме ванны и туалета; кухня в базе тоже линолеум

## Как перенести вручную в https://github.com/rishat11/Design

1. Откройте репозиторий → **Add file** → **Upload files**
2. Перетащите `README.md`, `SMETA.md`, `smeta.csv`
3. Перетащите папку `visuals` или все PNG из неё
4. **Commit changes**

Не нужны ни `curl`, ни Origin CLI.
